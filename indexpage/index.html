01 · 背景与简介

资料很多，找到却很难

企业内部沉淀了大量视频课程、PDF 文档与 PPT 课件，却分散在不同系统、 命名各异、格式不一。学习者靠关键词碰运气，管理员靠手工整理—— 这正是传统课件管理软件止步的地方。

🔎

一句话定位

以「AI 智能搜索」为核心入口的企业学习资料门户，前台检索浏览、后台全生命周期运营。

🧩

统一"课件"概念

把视频 / PDF / PPT 零散内容，用 课件—分类—标签—素材 四层结构聚合管理。

02 · 重点待解决问题

传统课件软件绕不过的四道坎

这些问题不是"再堆几个功能"能解决的，它们需要一种全新的、以理解为驱动的思路。

🎯

检索命中率低

关键词匹配无法理解模糊诉求，"项目管理相关的课程"常常一无所获，学习者被大量无关结果淹没。

🗂️

内容割裂、格式繁杂

视频 / PDF / PPT 各自为政，缺乏统一素材库；PPT 往往必须下载才能看，体验割裂。

🔐

权限粗放、难以受控

敏感课件要么全员可见、要么完全隔离，缺乏"可见可搜、按需解锁"的柔性访问控制。

🧱

运营靠手工、结构易失控

分类层级混乱、标签重复、素材与课件关系靠人肉维护，规模化后迅速失控。

03 · 解决方案

把 AI 装进课件培训的每一个环节

核心差异：不是给旧软件"加个搜索框"，而是让大模型成为贯穿检索、处理与浏览的能力底座。

🤖

AI 搜索 · LLM-to-SQL

自然语言诉求由大模型（qwen-plus）实时翻译成数据库查询（NL2SQL），把模糊语义精准映射到具体课件；无 Key 或超时则自动降级到 ILIKE 关键词兜底。

🛡️

安全可控的 AI 边界

LLM 生成的 SQL 必须通过 7 道白名单校验闸（单语句 / 无注释 / 仅 SELECT / 表白名单 / 强制 LIMIT 等）并在只读事务中执行，让 AI 强大而收敛。

🖥️

AI 驱动的在线浏览 (P-VIEWER)

PPT 上传时由后端自动转换为 PDF，前端用 PDF.js 行内渲染；视频流式播放、PDF 连续阅读，无需下载即可"边搜边看"。

🔑

柔性受控访问 (AccessToken)

受限课件对所有用户"可见可搜"，仅在进入详情时校验访问令牌，SHA-256 + 常量时间比对，支持一键重新生成与即时吊销。
