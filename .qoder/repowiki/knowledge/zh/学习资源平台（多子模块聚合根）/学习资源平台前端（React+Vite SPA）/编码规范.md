- API 方法统一返回 Promise<T>，内部通过 `unwrap(apiClient.xxx(...))` 剥离 `{data}` 信封，调用方无需处理响应包装。
- 需要鉴权或解锁的公开接口通过 `tokenHashHeaders(coursewareId)` 从 `useTokenStore.getState().unlockedByCourseware` 读取已缓存的 tokenHash 并以 `X-Token-Hash` 头发送，避免依赖 Set-Cookie 写入时机。
- 前台视图切换不依赖 React Router 子路由，而是通过 `useViewStore.go({ view, q, id, coursewareId })` 修改 URL query 并 `replaceState`，再由 `PublicShell` 根据 `view` 值条件渲染对应页面组件。
- 每个业务域在 `src/api/index.ts` 中以命名对象（如 `CategoryAPI`、`CoursewareAPI`）聚合 CRUD 方法与对应 TS 类型，保持前后端字段一致。
- 大体积第三方库（pdfjs-dist）通过 `optimizeDeps.exclude` 排除预构建，改为运行时动态 import，避免 HMR 卡顿。
