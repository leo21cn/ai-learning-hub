- 脚本入口统一采用 `def main() -> None:` + `if __name__ == "__main__": main()` 模式，便于被其他脚本或测试 import 而不触发执行。
- 对 SQLite 引擎一律使用 `create_engine(url, connect_args={"check_same_thread": False}, poolclass=StaticPool)` 分支，非 SQLite 则走默认 engine。
- 通过 `sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))` 把脚本所在目录前置到导入路径后再 `from app.*` 导入，避免依赖包安装位置。
- 对外部命令（ffprobe）调用包裹 try/except 捕获 `FileNotFoundError`、`TimeoutExpired`、`CalledProcessError` 并返回 None，保证单条失败不影响整体遍历。
