- PowerShell 脚本统一使用 `OutStep/OutOk/OutWarn/OutErr` 四色输出函数打印进度，并以 `[CmdletBinding()] param(...)` 暴露开关参数（如 `-SkipBuild`、`-SkipNginx`、`-WaitHealthyTimeout`）。
- 远程命令一律通过 `ssh -i $Key -o BatchMode=yes -o StrictHostKeyChecking=accept-new` 无交互执行，且用分号 `;` 而非 `&&` 拼接命令以兼容 PowerShell 5.1。
- 环境变量集中从同目录 `.env` 解析后注入到 `Env:\` 命名空间，再由 `docker stack deploy` 的 `environment:` 或 `env_file:` 传入容器，敏感项（SSH Key、DB 密码、JWT Secret）不入版本库。
- 健康检查采用分层策略：Compose 层定义 `healthcheck`（wget/curl 探测 `/api/public/health`），PowerShell 侧再轮询 `docker stack ps` 或 `compose ps --format json` 直到状态为 Running/healthy。
