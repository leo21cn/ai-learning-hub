- 构建与入口：`vite.config.ts` 配置 `@` 别名、`/api` 与 `/admin` 代理到后端 `127.0.0.1:18765`，`pdfjs-dist` 通过 `optimizeDeps.exclude` 交由运行时动态加载；`index.html` 由 `main.tsx` 挂载根组件。
- 路由分层：`src/App.tsx` 使用 `react-router-dom`，前台所有页面共享根路径 `/`，通过 `stores/view.ts` 的 `view` 查询参数在 `PublicShell` 内条件渲染（home/result/locked/detail/viewer），`/admin/*` 走独立子路由并由 `AdminGuard` 守卫。
- 状态层：`zustand` 全局 store 按领域拆分——`view.ts`（URL ↔ store 双向同步，含 `hydrateViewFromUrl`/`syncViewFromUrl`/`bindViewToPopState`）、`token.ts`（解锁 tokenHash 缓存）、`admin.ts`（登录态）、`toast.ts`（全局提示）。无 React Query，数据请求直接调用 API 层。
- API 层：`src/api/index.ts` 以模块对象形式导出 `AuthAPI`/`CategoryAPI`/`TagAPI`/`MaterialAPI`/`AccessTokenAPI`/`AccessSessionAPI`/`AccessTokenUsageAPI`/`CoursewareAPI`/`PublicCoursewareAPI`，统一经 axios 实例 `apiClient` 发起并 `unwrap` 解包 `{data}` 信封；解锁流程通过 `X-Token-Hash` 头绕过 Set-Cookie 时序问题。
- 媒体能力：`src/lib/pdfjs.ts` 封装 PDF.js 懒加载与高 DPI canvas 渲染；`pages/public/viewer/` 下 `PdfReader.tsx`/`SlideshowViewer.tsx`/`VideoPlayer.tsx` 分别承载三种素材类型，由 `Viewer.tsx` 串联播放序列。
- 公共 UI：`components/` 提供 `ConfirmDialog`、`Logo`、`Toast`；`layouts/AdminLayout.tsx` 为管理后台壳。
- E2E：`e2e/` 使用 Playwright，`playwright.config.ts` 定义测试工程，`scripts/copy-pdfjs-worker.mjs` 在构建后复制 worker 文件。
