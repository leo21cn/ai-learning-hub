模块按运行环境划分为两个并列子目录：
- `deploy/ecs/`：面向阿里云 ECS（ARM64）的 Swarm Stack 发布管线。入口为 PowerShell 5.1 脚本 `publish.ps1`，依次执行：加载 `.env` → 通过 `docker buildx --platform linux/arm64` 构建 backend/frontend 镜像 → `docker save` 打包 → `scp` 推送至 `ECS_REMOTE_DIR` → SSH 远程执行 `remote-setup.sh` / `db-init.sh` / `docker load` / `docker stack deploy -c compose.yml learning-hub` → 轮询 `docker stack ps` 等待 Running → 可选阶段式调用 `nginx-vhost-apply.sh phase1|phase2` 签发 Let's Encrypt 证书并注入 nginx-gateway 的 80/443 server block，再用 `persist-cert-mount.py` 把证书 bind mount 持久化到 nginx-gateway 的 compose.yml。
- `deploy/local/`：面向 Windows + Docker Desktop 的本地编排，`docker-compose.yml` 拉起 postgres/backend/frontend 三服务并通过 healthcheck 串联依赖；`deploy-lh-local.ps1` 自动探测 named pipe/TCP 连接 Docker daemon、重建镜像、`up -d` 并校验 OpenAPI 注册新接口。
- `doc/deploy/README.md` 作为可执行的部署手册骨架，记录复用资源清单、待补齐章节与 P0-P2 优先级，与 `compose.yml` 中外部网络/卷声明一一对应。
依赖方向单向：PowerShell 脚本 → 远端 bash/python 辅助脚本 → Docker CLI → Swarm/Compose 引擎；本模块不反向依赖后端/前端源码，仅通过 `../backend`、`../frontend` 作为 Dockerfile context 引用。
