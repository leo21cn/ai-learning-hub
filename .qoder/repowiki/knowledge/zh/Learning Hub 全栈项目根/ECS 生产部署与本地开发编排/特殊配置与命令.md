ECS 发布前需先复制 `deploy/ecs/.env.example` 为 `.env` 并填入 SSH 私钥路径、`POSTGRES_NETWORK_NAME`、`NGINX_NETWORK_NAME`、`DATABASE_*`、`LH_DOMAIN`、`ACME_EMAIL` 等字段；随后在 Windows 主机上执行 `cd deploy/ecs && .\publish.ps1 [-SkipBuild] [-SkipNginx]`。本地开发执行 `cd deploy/local && .\deploy-lh-local.ps1`，默认通过 `npipe:////./pipe/docker_engine` 连接 Docker Desktop。
