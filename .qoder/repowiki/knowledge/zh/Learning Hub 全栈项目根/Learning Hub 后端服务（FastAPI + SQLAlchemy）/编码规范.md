- 所有 API 路由放在 `app/api/{admin|public}/` 下，按领域拆文件并在 `main.py` 集中 `include_router`，禁止跨包直接 import 路由对象。
- 业务逻辑一律下沉到 `app/services/*`，API 层仅负责参数解析与调用 service，不得直接操作 ORM。
- 请求/响应体统一使用 `app/schemas/*` 中的 Pydantic v2 模型，配合 `schemas.fail` / `envelope_or_business` 输出标准化错误信封。
- 数据库访问通过 `app.db.get_db()` 依赖注入，每个请求一个 Session，不在模块级持有连接。
- 配置全部走 `app.core.config.get_settings()` 单例，禁止在业务代码中直接读取环境变量。
