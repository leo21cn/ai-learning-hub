## 引言
本指南面向 Learning Hub 管理后台的页面开发者，聚焦以下目标：
- 统一 CRUD 页面的开发模式（列表、新增/编辑表单、删除确认、批量操作）
- 课件管理复杂表单（分类树选择、标签多选、素材拖拽排序、访问令牌绑定）
- 素材管理上传（类型检测、大小限制、错误友好提示）
- 分类与标签的树形结构与关联维护
- 访问令牌生成、配置与使用统计
- 登录认证与安全会话管理
- 权限控制、数据验证与用户体验优化方案

## 架构总览
管理后台整体交互流程：浏览器通过 Axios 客户端调用 /api 前缀接口，后端路由受 admin 鉴权中间件保护；登录成功后由后端签发 JWT 并写入 HttpOnly Cookie，后续请求自动携带。

```mermaid
sequenceDiagram
participant U as "管理员浏览器"
participant FE as "前端 AdminLayout/Login"
participant API as "后端 /api/auth"
participant MW as "鉴权中间件"
participant Svc as "业务服务"
U->>FE : 输入 Admin Token 提交登录
FE->>API : POST /api/auth/admin {token}
API->>MW : verify_admin_token(token)
MW-->>API : 校验结果
API->>API : issue_admin_jwt()
API-->>FE : Set-Cookie LH_ADMIN_SESSION + 返回 adminId/expiresAt
FE->>FE : 持久化 expiresAt(本地)
U->>API : 访问受保护资源(携带Cookie)
API->>MW : get_admin_principal()
MW-->>API : 解析JWT成功
API->>Svc : 执行业务逻辑
Svc-->>API : 返回数据
API-->>U : 业务响应
```

## 依赖关系分析
- 前端
  - api/index.ts 聚合所有业务 API，统一解包 envelope
  - api/client.ts 提供 axios 实例与拦截器
  - stores/admin.ts 管理登录态与本地过期

- 后端
  - 所有 /api/admin/* 路由通过 get_admin_principal 依赖进行鉴权
  - auth.py 负责登录/登出与 Cookie 设置
  - 各业务路由调用 services 层实现
