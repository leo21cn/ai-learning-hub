## 1. 简介

Learning Hub 是一个面向企业内部的**学习资料检索与阅读平台**。在这里，你可以：

- 用一句话（自然语言）描述你想学的方向，让 AI 帮你找到合适的课件
- 直接在线打开视频、PDF、PPT 课件，无需先下载到本地
- 一键下载老师/运营分发的 ZIP 压缩包（源码 / 示例工程 / 资料合集）
- 拿到由讲师或运营分发的"访问令牌"后，解锁受保护的内部资料

整个过程**不需要注册账号**——只要能访问内部网，就能用。

## 2. 快速上手

### 2.1 进入系统

在浏览器地址栏输入你公司提供的 Learning Hub 地址，例如：

```
https://learning-hub.your-company.com/
```

打开后，你会看到这样的极简首页：

```
   ┌──────────────────────────────────────┐
   │                                      │
   │         Learning Hub                 │
   │                                      │
   │  ┌────────────────────────────┐      │
   │  │ 请帮找一下项目管理相关的课程 │  [搜索] │
   │  └────────────────────────────┘      │
   │                                      │
   └──────────────────────────────────────┘
```

整个首页只有一个标题和一个搜索框，目的就是让你**最快地进入学习**。

### 2.2 三步找到课件

1. **在搜索框里输入**你想学习的内容（中文、英文都可以）
2. **点击"搜索"按钮**（或直接按键盘上的 Enter 键）
3. 在结果列表里**点击课件标题**进入详情

就这么简单。

## 3. 搜索课件

### 3.1 怎么输入关键词

- **自然语言**：可以直接说人话，比如：
  - 项目管理入门
  - 帮我看看有没有敏捷开发相关的视频
  - 新员工入职培训资料
- **关键词**：也可以只输入几个字，比如：
  - PPT 模板
  - 财务报表
  - Q3 OKR

> **小贴士**：尽量用 2~15 个字的关键词，命中率最高。句子太长有时反而会让结果变窄。

### 3.2 搜索结果页长什么样

搜索提交后，你会进入结果页：

```
┌──────────────────────────────────────────────────┐
│  Learning Hub   [搜索框：项目管理___]  [搜索]    │  ← 顶部条
├──────────────────────────────────────────────────┤
│  🏷 AI 智能搜索    找到 6 个课件    [清空全部]    │  ← 工具栏
├──────────────────────────────────────────────────┤
│  📚 项目管理入门                           🔒    │  ← 命中课件
│      项目运营 / 通用 / 入门                    │
│                                                  │
│  📚 敏捷开发实战                                  │
│      软件工程 / 敏捷                             │
│                                                  │
│  📚 OKR 工作法                                    │
│      组织变革 / 目标管理                         │
└──────────────────────────────────────────────────┘
```

每一项包括：

| 元素 | 含义 |
| ---- | ---- |
| 📚 图标 | 课件缩略标志 |
| 课件标题 | 点击进入详情 |
| 🔒 角标 + 受令牌保护 标签 | 受限课件，需要访问令牌才能查看（详见 §5） |
| 灰色文字 | 课件所属分类（从根到三级） |

### 3.3 状态提示

| 状态 | 看到什么 | 怎么办 |
| ---- | -------- | ------ |
| 加载中 | **⏳ AI 搜索中，请稍候…** | 稍等 1~2 秒 |
| 命中为空 | 📭 + **没有找到匹配的课件，试试调整搜索条件** | 换个关键词再试 |
| 命中正常 | 命中课件列表 | 点标题进入详情 |
| 网络异常 | **搜索失败，请稍后重试** | 检查网络后点重试按钮 |

### 3.4 调整搜索

- **修改搜索词**：直接在顶部搜索框里改，按 Enter 或点搜索
- **回到首页**：点顶部 **Learning Hub** Logo，或点工具栏右侧的 **清空全部**

### 3.5 看到"降级中"标识怎么办

偶尔你会在结果页工具栏看到：

```
🏷 AI 智能搜索 · 降级中
```

这表示后台的 AI 模型暂时不可用，系统已自动切换到传统的关键词检索模式。**功能完全正常**，只是不会按语义相关度排序——你可以放心使用。如果很在意 AI 排序效果，可以稍后再试一次。

详情页右上角的 **返回搜索** 按钮会把你带回搜索结果页，**保留刚才的搜索关键词**。

## 5. 受限课件与访问令牌

部分内部资料会标记为"受限"，意味着不是所有同事都能直接看到内容，需要先输入**访问令牌（Token）**才能解锁。

### 5.1 受限课件长什么样

在搜索结果列表中，受限课件标题右侧会带一个 🔒 角标：

```
📚 项目管理入门（内部资料）              🔒 受令牌保护
```

鼠标悬停在该课件上时，浏览器读屏器会提示：**该课件需要访问令牌**。

### 5.2 第一次点击：进入"解锁"页

点击受限课件，如果你之前没有解锁过，会进入锁定页：

```
┌──────────────────────────────────────────────────┐
│  Learning Hub                       [返回搜索]    │
├──────────────────────────────────────────────────┤
│           项目管理入门（内部资料）                  │
│                                                  │
│   这是一个受令牌保护的课件，请输入访问令牌以查看详情 │
│                                                  │
│   ┌────────────────────────────────┐              │
│   │ 请输入访问令牌                  │              │
│   └────────────────────────────────┘              │
│                                                  │
│         [   解锁   ]                              │
│         返回搜索                                  │
└──────────────────────────────────────────────────┘
```

### 5.3 怎么获取令牌

令牌由公司内部的讲师、运营或资料管理员通过线下渠道（邮件、IM、文档）发放，**不在 Learning Hub 页面内**。令牌是一串由数字与大写字母组成的字符，例如：

```
AB12CD34EF56GH78IJ90KL34
```

### 5.4 输入令牌

1. 在输入框中粘贴或输入你收到的令牌
2. 点击 **解锁** 按钮

| 情况 | 系统提示 | 下一步 |
| ---- | -------- | ------ |
| 令牌正确 | （直接进入详情页） | 可以正常浏览素材 |
| 令牌无效 | **令牌无效，请检查后重试** | 检查拼写、确认是否过期，重新输入 |
| 令牌已失效 | **令牌已失效，请重新输入** | 联系讲师或管理员重新获取 |
| 网络异常 | **解锁失败，请稍后重试** | 稍后再试 |

### 5.5 一次输入，永久记住

解锁成功后，系统会在你的浏览器里**记住这个令牌**。之后：

- ✅ 关闭浏览器后再打开同一个课件 → 不需要重新输入
- ✅ 刷新页面 → 不需要重新输入
- ✅ 在搜索结果中再次点击该课件 → 不需要重新输入
- ❌ 在另一台电脑或浏览器访问 → 需要重新输入（这是为了安全）
- ❌ 管理员重新生成了令牌 → 旧令牌失效，会自动提示你重新输入

### 5.6 不小心点错了

如果在锁定页不想继续，可以点击 **返回搜索** 返回结果列表。**这不会删除已经记住的令牌**。

## 6. 在线浏览素材

当你点击某个素材的 **在线浏览** 按钮时，系统会按素材类型提供不同的阅读方式。

### 6.1 视频素材（.mp4）

进入视频浏览页后，你会看到：

- **左侧**：黑色背景的视频播放器
  - 使用浏览器原生控件（播放 / 暂停 / 进度条 / 音量 / 全屏）
  - 默认**不会自动播放**，需要你主动点击播放
- **右侧**：信息面板
  - 文件名
  - 类型（视频）
  - 时长（如 12:34）
  - 文件大小
  - **下载到本地** 链接（兜底）

操作要点：

- 点 ▶ 按钮播放
- 再次点击可暂停
- 支持键盘 **空格** 播放/暂停、**←** **→** 倒退/快进 5 秒
- 视频支持 HTTP Range 加载，可以任意拖动进度

### 6.2 PDF 文档（.pdf）

PDF 阅读页提供类似 Word 的连续滚动阅读体验：

- **顶部工具条**：返回 / 缩放 − / 当前比例 / 缩放 + / 下载到本地
- **主体**：连续滚动的页面（不再是左右翻页）
- **右下角气泡**：当前页码 **第 3 / 18 页**，自动跟随滚动更新
- **缩放比例**：75% / 100% / 125% / 150% / 200%，默认 **125%**
- **双击**：放大 / 还原页面

操作要点：

- 用鼠标滚轮上下滚动
- 想要更清楚时点 **缩放 +**
- 读完整篇后点顶栏 **返回** 回到课件详情

### 6.3 PPT / PPTX 演示文稿

PPT 演示文稿被自动转换为 PDF 后提供**幻灯片式**阅读：

- **暗色背景**保护眼睛
- **底部控制条**：
  - **上一张**
  - 页码 **3 / 20**
  - **下一张**
  - **全屏**
- **键盘快捷键**：
  - **←**（左箭头）：上一张
  - **→**（右箭头）：下一张
- **首末页边界**：到第一张时 **上一张** 按钮会自动禁用（显示"已是第一张"），到最后一张时同理
- **全屏**：点 **全屏** 按钮进入演讲模式，按 Esc 退出

> **小贴士**：如果你想保存原始 PPT 文件用于修改/二次编辑，记得点顶栏 **下载到本地**，下载的是原始 .pptx 文件（不是 PDF）。

### 6.4 ZIP 压缩包（.zip）

ZIP 素材**不提供在线浏览入口**，课件详情页直接显示 **下载到本地** 按钮，点击后浏览器开始下载原 `.zip` 文件到你的电脑。下载完成后，用解压软件（如 7-Zip、WinRAR、系统自带）打开。

适用场景：

- 老师分发的项目源码、示例工程、配置文件合集
- 培训资料的附件包（含多个文档 / 图片）
- 不便在线预览的多文件合集

使用要点：

- 受限课件中的 ZIP 也需要先解锁才能下载（详见 §5）
- 如果浏览器没有自动下载，请检查浏览器右上角的下载提示，或在设置里允许该网站下载多个文件
- 下载得到的压缩包可直接在本地解压后使用，无需联网

### 6.5 浏览页顶栏

所有素材浏览页顶部都有统一顶栏：

```
[← 返回]  PM-101.mp4    [下载到本地]      Learning Hub
```

| 元素 | 作用 |
| ---- | ---- |
| **← 返回** | 返回课件详情页 |
| 文件名 | 当前浏览的素材名 |
| **下载到本地** | 浏览器触发下载，保存原文件到本地 |
| **Learning Hub** | 返回首页（空态），会清掉当前课件的访问令牌记忆 |

> ZIP 类型的素材**不会进入浏览页**；如直接访问 `/viewer?id=<zip_id>`，系统会提示“该素材仅支持下载，请在课件详情页使用下载按钮获取文件”。

### 6.6 浏览器不支持时怎么办

如果你的浏览器版本较老（详见 §9），部分高级功能（如 PDF 在线渲染、PPT 转换）可能不可用。系统会显示：

```
该浏览器不支持在线预览，请下载到本地查看
```

此时：

1. 点 **下载到本地** 把文件保存到本地
2. 用本地应用打开（视频用播放器、PDF 用 PDF 阅读器、PPT 用 WPS / Office）
3. 如有需要，请升级浏览器

## 7. 导航与返回

### 7.1 在不同页面之间切换

| 当前位置 | 想回到 | 怎么操作 |
| -------- | ------ | -------- |
| 搜索结果页 | 首页空态 | 点顶部 **清空全部**，或点 Logo |
| 课件详情页 | 搜索结果页 | 点顶栏 **返回搜索**，或浏览器 ← 后退 |
| 课件详情页 | 首页空态 | 点 Logo（**会清掉当前课件的访问令牌记忆**） |
| 素材浏览页 | 课件详情页 | 点顶栏 **← 返回**，或浏览器 ← 后退 |
| 素材浏览页 | 首页空态 | 点 Logo |
| 锁定页 | 搜索结果页 | 点 **返回搜索** |

### 7.2 浏览器前进 / 后退按钮

Learning Hub 是单页应用（SPA），但仍然支持浏览器的 **←** / **→** 按钮：

- **←** 后退 → 通常等同"返回上一层"
- **→** 前进 → 同理

如果你发现前进/后退的行为与你预期不一致，**优先使用页面顶部的"返回"按钮**。

### 7.3 关闭浏览器再打开

关闭浏览器后：

- ✅ 你的搜索结果**不会**保存
- ✅ 课件的访问令牌在 5 分钟内仍可在同一浏览器、同一域下复用
- ❌ 私密浏览模式下关闭后所有记忆都会清空

## 8. 常见问题 FAQ

### Q1：搜索"项目管理"一条结果都没有？

可能的原因：

- 数据库里目前确实没有相关课件
- 关键词太具体（如 2024Q3 OKR 复盘材料）
- 搜索词包含特殊符号（如 ? * [）

建议：

- 改成更宽泛的关键词（如 项目管理 → 项目）
- 换个相近词（如 敏捷开发 → Scrum）
- 联系管理员补充课件

### Q2：受限课件提示"令牌无效"，但我刚拿到的令牌

请检查：

1. **复制时是否多/少了空格**？令牌通常 24 位不带空格
2. **大小写**？令牌区分大小写
3. **重新生成过**？管理员可能已经重新生成了令牌，需要重新索要
4. **令牌归属**？确认这个令牌确实是为这门课件颁发的

### Q3：以前能打开的受限课件突然提示"令牌已失效"

大概率是因为**管理员重新生成了令牌**（出于安全考虑）。请联系讲师或管理员，索要最新令牌即可。

### Q4：点"在线浏览"PPT 一直显示"正在生成预览"

PPT 预览 PDF 是后台**异步生成**的，首次上传后需要等待 30 秒~60 秒。请：

- 等待几分钟后刷新页面再试
- 或暂时用 **下载到本地** 直接打开原始 PPT 文件

### Q5：PPT 下载下来是 PDF 还是 PPT？

- **下载到本地**：下载的是**原始 .pptx 文件**，可以用 WPS / Office 编辑
- **在线浏览**：显示的是**转换后的 PDF 版本**，只读，方便阅读

### Q6：为什么我打开 PDF 课件时浏览器直接下载了？

你的浏览器版本太老（见 §9），不支持 PDF 行内渲染。请：

- 升级到最新版 Chrome / Edge / Firefox
- 或使用 **下载到本地** 把 PDF 保存到本地，用本地 PDF 阅读器打开

### Q7：视频加载很慢 / 卡顿

可能原因：

- **公司网络带宽不足**：建议错峰观看或使用有线网络
- **视频文件较大**：可先 **下载到本地** 后观看
- **多人同时观看同一课件**：联系管理员评估是否需要扩容

### Q8：我能在手机上用吗？

当前版本对移动端做了"不破版"的兼容，但**桌面体验（Chrome / Edge 浏览器）才是最佳实践**。如果只是查询课件列表、简单浏览，手机也基本可用；但完整的素材浏览功能（特别是 PDF 长文档）建议在桌面端进行。

### Q9：学习进度会被记录吗？

**当前版本不会**。v1.4 引入了**访问记录**功能，但仅供管理员统计"令牌使用情况"（例如某个部门是否真的看了那份保密资料），**不会记录到你个人**。Learning Hub 不会展示个人学习时长、阅读进度等数据。

### Q10：发现课件内容有错 / 需要补充资料？

请联系公司内部对应的**课件管理员**或**资料运营**，他们会通过后台更新或新增课件。学习者无法在前台直接编辑。

- 必须能访问公司内部网（公网域名通常为 https://learning-hub.your-company.com）

- 上行带宽建议 ≥ 2 Mbps（在线流畅观看视频）

### 9.4 不需要安装任何插件

Learning Hub 是纯 Web 应用，**不需要安装**任何浏览器插件、Flash、Java Applet 等。

按下面的顺序排查，多数问题可以自己解决：

1. **刷新页面**（F5 或 Ctrl/Cmd + R）
2. **换一个浏览器**试试（特别是 Chrome 和 Edge 切换）
3. **清浏览器缓存**（设置 → 隐私 → 清缓存）
4. **用 下载到本地 兜底**（任何素材都可以下载到本地打开）
5. **联系管理员**（带错误截图）
