# 08. 验收标准

> 本章按模块给出验收用例与通过条件。所有用例均来源于规格说明书，可作为自动化测试的雏形。

## 1. 验收总则

- 验收对象：`http://localhost`（前台）与 `http://localhost/admin`（后台）。
- 验收方法：Browser Agent 端到端走查 + 接口契约校验。
- 通过标准：所有用例 100% 通过；存在 P0 用例失败则整体不通过。
