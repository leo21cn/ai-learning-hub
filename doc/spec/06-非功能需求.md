# 06. 非功能需求

> 本章定义 Learning Hub 在性能、安全、可用性、兼容性、容量、运维等方面的非功能需求。所有阈值与基线均以"中等规模企业内部使用"为参考规模。

## 1. 性能

### 1.1 响应时间

| 场景 | 目标 | 度量方式 |
| ---- | ---- | -------- |
| 前台首页加载 | ≤ 1s（首屏） | TTFB + 首屏渲染 |
| AI 搜索响应 | P95 ≤ 2s | 客户端埋点 |
| 后台列表加载 | P95 ≤ 1.5s | 客户端埋点 |
| 后台保存（课件 / 分类 / 标签） | P95 ≤ 1s | 客户端埋点 |
| 素材上传（200MB） | 取决于网络，UI 提供进度条 | 客户端埋点 |
| PPT 转 PDF（后台异步调用 LibreOffice） | ≤ 60s（默认 `ppt_convert_timeout=60`，可配） | 后端 logger；超时降级为下载链接 |

### 1.2 吞吐与并发

| 指标 | 基线 |
| ---- | ---- |
| 前台 QPS（搜索） | ≥ 50 QPS |
| 后台并发操作员 | ≥ 10 |
| 同时上传素材 | ≥ 5 |

## 2. 安全

### 2.1 鉴权

- 管理后台全部 API 必须经过 Token 鉴权；Token 不正确返回 403。
- 前台搜索 API 公开，但需有基础防滥用（限流）。

#### 2.1.1 课件访问 Token

- 访问 Token（AccessToken）是课件级 ACL，不绑定学习者个人身份，不参与 `JwtAuthFilter` 路径。
- 在课件详情接口进入受限课件前判定：调用方必须传入与该课件关联的有效 Token。未传入或失效均返回 401/403。
- 拆分为两个动作：详情接口本身持有 `token_revoked` 状态码语义，用于告知前端本地记忆已不可信。
- 后台重置、与课件解除关联后，不会迟于 1 个请求周期生效。

### 2.2 数据

- Admin Token 不应硬编码到前端；当前演示值 `demo` 仅用于本地。
- 素材文件存储路径（`/app/storage/documents`）建议挂载到对象存储或受控 PV。
- 上下行均启用 HTTPS（生产环境强制）。
- AccessToken 仅持久化 `value_hash`（SHA-256）；原值仅在创建 / 重新生成瞬间返回给管理员，后续响应、日志、客户端存储一律不得出现明文。

### 2.3 防护

- 上传文件需校验扩展名白名单与大小上限。
- 上传接口需有速率限制与用户配额。
- 富文本描述字段需做 XSS 过滤（虽然当前是多行文本，但保留扩展能力）。
- AccessToken 校验应使用常量时间哈希比较（避免计时暗示）。
- AccessToken 校验接口需启用限流：同 IP + 同 Token 每分钟 ≤ 10 次，超出后临时限流 1 分钟。
- `GET /api/public/materials/{id}` 与 `/api/public/materials/{id}/stream` 预览流地址同样受 60/minute/ip 限流约束，防爬。

## 3. 可用性

- 后端服务目标可用性 ≥ 99.5%（按月计）。
- 关键操作（新建课件、搜索、上传素材）失败需有可读的错误提示。
- 关键写入操作记录审计日志（操作人、时间、对象、动作）。

## 4. 兼容性

### 4.1 浏览器

| 浏览器 | 最低版本 |
| ------ | -------- |
| Chrome | 100+ |
| Edge | 100+ |
| Safari | 15+（PDF.js 4.x 需要 Safari 14+，但幻灯片组件需 15+） |
| Firefox | 100+ |

> PDF.js 4.7 需现代浏览器（Chromium 90+ / Firefox 88+ / Safari 14+）；在老旧浏览器访问 P-VIEWER 时由前端兜底为“下载到本地”提示页。

### 4.2 屏幕

- 桌面优先（≥ 1280px 宽）。
- 不保证移动端可用；但关键页面在 768px 宽度下不破版。

### 4.3 语言

- UI 当前仅简体中文，不提供 i18n 切换。

## 5. 容量

| 维度 | 容量目标 |
| ---- | -------- |
| 课件总数 | 10000 |
| 素材总大小 | 500GB |
| 单文件大小 | ≤ 200MB |
| 分类节点数 | ≤ 500 |
| 标签数 | ≤ 1000 |
| AccessToken 总数 | ≤ 200 |

## 6. 可观测性

- 关键接口记录访问日志（路径、状态码、耗时、用户标识）。
- 异常统一上报（5xx / 业务异常）。
- AI 搜索记录请求 query、命中数、耗时，用于效果分析。
- AccessToken 创建、重新生成、删除、与课件绑定 / 解绑需记录审计日志（操作人、时间、动作、对象）。

## 7. 可维护性

- 模块边界清晰：课件 / 分类 / 标签 / 素材各自独立服务。
- 公共异常码、错误消息集中管理，避免散落。
- 数据库迁移脚本纳入版本控制。

## 8. 合规与隐私

- 不收集学习者个人身份信息（前台匿名）。
- 管理员操作记录至少保留 180 天。
- 素材版权由上传者负责，平台提供必要的提示与免责说明。

## 9. 部署与运维

- 当前实例部署于 Docker 容器内（路径 `/app/storage/documents`）。
- 推荐使用对象存储或受控 PV 作为素材存储后端。
- 配置变更通过环境变量注入，避免硬编码。
- 推荐 CI/CD 流程：构建 → 推送镜像 → 远程 ECS 部署 → 远程验证（不在本地环境验证）。

## 10. 服务端监控基线（v1.0 推荐实现）

> 本节作为服务端可观测性下限补充；指标应接入 Prometheus / Grafana 或阿里云 ARMS。

| 指标 | 基线 | 说明 |
| ---- | ---- | ---- |
| `lh.http.request.duration`（P95） | ≤ 300ms | 后台 CRUD 接口 |
| `lh.http.request.duration.search`（P95） | ≤ 2s | 含 LLM 调用；含降级到关键词检索场景 |
| `lh.db.query.duration`（P95） | ≤ 50ms | 单条 DB 查询耗时 |
| `lh.llm.call.duration`（P95） | ≤ 1.5s | 仅 LLM 调用本身；含超时降级触发 |
| `lh.llm.timeout.rate` | ≤ 5%（5 分钟滑动窗口） | 超时告警阈值 |
| `lh.material.upload.duration`（P95） | ≤ 60s（200MB 文件） | 含网络 |
| `lh.token.unlock.fail_rate` | ≤ 30%（5 分钟滑动窗口） | 异常偏高需排查 |
| `lh.error.5xx.rate` | ≤ 0.5% | 服务端错误率 |

> 服务端日志均需包含 `X-Request-Id`（与响应头同值），便于跨服务对位。
